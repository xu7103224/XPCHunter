## 九、`SendWriteMemoryIoControl` 的实参映射（2026-09-29，用于精确转写）

调用方 `CmdWriteProcessMemoryEx`(0x1400749A0) **可反编译**，其伪代码第 76 行给出：

```c
v7 = SendWriteMemoryIoControl((int)&v39, Address[2], v9, v8, v5, v29, Address[4], v10);
//                           OutFlag(&v39) ProcessId  PageIdx AddrField pOutBuf OutSize ResultBuf Flag
```

由此确定 8 个形参（也解决了 `arg_XX` 槽位命名）：

| 形参 | 调用点实参 | 函数体内对应 |
|---|---|---|
| 1 OutFlag | `&v39` | `*(BYTE*)rcx = 1`（序言）；`arg_0` 即此槽 |
| 2 ProcessId | `Address[2]` | 作 IOCTL 句柄传 `SendDeviceIoControlWithRetry` |
| 3 PageIndex | `v9` | 循环里 `cmp PageIndex, 1`（`arg_18`） |
| 4 AddressField | `v8` | `cmp r9d,2; ja 失败`；作类型传子调用（`arg_10`） |
| 5 pOutputBuffer | `v5` | 作子调用第 6 实参（`arg_20` → rsi 初值） |
| 6 OutputSize | `v29` | **`arg_28` → r15d**（剩余量初值，每轮递减） |
| 7 ResultBuffer | `Address[4]` | 游标基址（`arg_30`） |
| 8 Flag | `v10` | `cmp Flag, 1`（`arg_38`） |

> 与读版对照：读版第 5/6/11 实参是 `v5/a4/v35`，本版是 `v5/v29/Address[4]` ——
> 说明写版把"结果缓冲"（`Address[4]`）与"输出缓冲"（`v5`）**分开传**，
> 而读版是合一的。这是两版的实质差异之一。

## 十、`SendWriteMemoryIoControl` 实参映射最终定案（2026-09-29）

**裁判 = 调用点反汇编**（0x140074A60–0x140074AD3，`CmdWriteProcessMemoryEx` 内），
不经任何推断：

```
140074A9B  mov  edx, 4 / mov r8d,edx / call ProbeForWrite    ; 校验结果缓冲可写
140074AA9  mov  [rsp+0B8h+var_80], r12b      ; ← 第 8 实参槽 (rsp+0x38)  = char
140074AAE  mov  rax, [r13+20h]
140074AB2  mov  [rsp+0B8h+var_88], rax       ; ← 第 7 实参槽 (rsp+0x30)  = [r13+0x20]
140074AB7  mov  dword ptr [rsp+0B8h+var_90], r14d ; ← 第 6 实参槽 (rsp+0x28) = dword
140074ABC  mov  [rsp+0B8h+var_98], rsi       ; ← 第 5 实参槽 (rsp+0x20)  = void*
```

**结论（形参表）**：

| # | 寄存器/槽 | 实参 | 类型（按传参宽度） |
|---|---|---|---|
| 1 | rcx | `&HeaderFlag` | `char *`（出标志） |
| 2 | rdx | `[r13+0x10]` | `__int64`（IOCTL 句柄） |
| 3 | r8d | `ebx` | `int`（页索引） |
| 4 | r9d | `r15d` | `int`（地址字段/类型） |
| 5 | rsp+0x20 | `rsi` | `void *`（输出缓冲） |
| 6 | rsp+0x28 | `r14d` | `SIZE_T`（大小，按 dword 传） |
| 7 | rsp+0x30 | `[r13+0x20]` | `__int64`（结果缓冲） |
| 8 | rsp+0x38 | `r12b` | `char`（标志） |

1. 我先前按"IDA `arg_XX` 显示名 = 形参序号"推断，得出 `arg_28`=OutputSize —— **错位一格**。
   函数体内：`arg_18`=第4实参(AddressField??)… 以本表为准（下文实现时逐条对齐）。
2. 我先前从调用方**伪代码变量名**（`v29`/`Address[4]`）推断"第 7 = ResultBuffer、第 8 = Flag"，
