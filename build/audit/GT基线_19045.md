# 19045 原始基线（真·同版本对照）

## 为什么需要它

此前用的 `gt_orig_live.bin` 来自 **build 18362** 的会话
（其 `GT[0x914] = 0x47BA = 18362`）。在本机上原始驱动同样报
`GT[0x914] = 0x47BA` —— 说明该槽是驱动**写入的目标版本常量**，
不是运行时读到的真实 build。派发因此走 18362 族
（`0x140023C2C`），该函数**会**写 0x18B-0x18E。

所以 0x18B-0x18E 是**真实缺失**，不是版本伪差异
（先前那条「伪缺失」结论作废）。

## 采集方法（可复现）

1. 把已签名的 `OrigDrv.sys` 推到 guest 的 `C:\Users\xuq\origdrv.sys`
2. `sc create OGT type= kernel binPath= C:\Users\xuq\origdrv.sys`
3. `sc start OGT` → STATE: 4 RUNNING
4. kd `!drvobj OGT` 取 DriverObject → `[+0x28]` 取 DriverSection
   → `[+0x30]` 取模块基址（本次 `fffff80411b10000`）
5. 原始 GT 基址 = 模块基址 + **0xa84f0**（LTCG 固定 RVA）
6. `.writemem <host路径> <GT基址> L24000` → `gt_orig_19045.bin`

产物：`build/audit/gt_orig_19045.bin`（147456 字节 = 18432 槽）
