# publish 目录脚本使用说明

每个脚本一个说明文件，按需查阅。

| 脚本 | 用途 | 谁用 |
|---|---|---|
| [publish_xpchsdk.bat](使用说明_publish_xpchsdk_bat.md) | 发布入口，一条命令完成编译+签名+打包 | 日常用这个 |
| [pack_xpchsdk.ps1](使用说明_pack_xpchsdk_ps1.md) | 打包逻辑本体，被 bat 调用 | 想改打包行为时 |
| [sign_xpchsdk.ps1](使用说明_sign_xpchsdk_ps1.md) | 只签名，产出 driver_pkg 目录 | 只想重新签名时 |
| [templates/XPCHunterDrv.inf](使用说明_INF模板.md) | 驱动包 INF 模板 | 改驱动安装参数时 |
| [templates/install_driver.bat](使用说明_install_driver_bat.md) | 本地调试用的驱动装/卸脚本 | 实验机调试时 |

## 最短路径

```bat
:: 正式发布（用 EV 证书签好，产出 driver_pkg 供你打 CAB）
publish\publish_xpchsdk.bat -PfxPath D:\ev.pfx -PfxPassword 口令

:: 本地测试（自签名）
publish\publish_xpchsdk.bat -TestSign
```

## 命名约定

```
publish_<产品>.bat   入口
pack_<产品>.ps1      打包逻辑
sign_<产品>.ps1      签名与驱动包生成
```

新增产品时复制一套改名，不要在 `publish/` 下出现无产品前缀的通用名。

## 编码约束（改脚本必看）

- `.bat` 必须**纯 ASCII + CRLF**。cmd 按 ANSI 解析，中文注释会变成乱码命令。
- `.ps1` 必须带 **UTF-8 BOM**。PowerShell 5.1 对无 BOM 的 UTF-8 按 ANSI 解析，
  中文注释会导致语法错误。
- 写 Windows 路径不要用 `"...\bin"` 这类字面量，`\b` `\x` 会被当转义吃掉。
  用 `Join-Path` 逐级拼接。
