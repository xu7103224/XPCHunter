# 第三步-2/3：Per-Monitor DPI + 状态列逐行着色（2026-10-28）

## 一、Per-Monitor DPI（FeDpi.c/.h + 应用清单）

### 实现

| 文件 | 内容 |
|---|---|
| `inc/FeDpi.h` / `src/FeDpi.c` | `FeDpiScale(96基准值)`、`FeDpiInit`、`FeDpiOnChanged` |
| `res/xpch_frontend.manifest` | `PerMonitorV2, PerMonitor` + Common-Controls 6.0 + Win10 supportedOS |

- `GetDpiForWindow` 用 `GetProcAddress` 动态取（Win10 1607+ API，避免旧系统加载失败）；
- `WM_DPICHANGED` → `FeDpiOnChanged`：更新基准、按系统建议矩形 `SetWindowPos`、
  触发一次 `WM_SIZE` 重排、整窗重绘；
- `WM_SIZE` 里的边距/固定高度改走 `FeDpiScale()`（客户区宽度本身已含 DPI，不重复缩放）；
- 构建脚本在 link 后用 `mt.exe` 把清单嵌入 `#1` 资源；找不到 mt.exe 时只告警不中断。

### 验证

```
dpiAware    = true/PM
dpiAwareness= PerMonitorV2, PerMonitor
Common-Controls 6.0.0.0 已声明
```

用 `mt.exe -inputresource:xpch_frontend.exe;#1` 反抽清单确认三处都在。
（首次抽取失败是因为 git-bash 把 `#` 当注释，加引号后正常。）

## 二、状态列逐行着色（FeTheme.c）

`CDDS_ITEMPREPAINT` 阶段除设置行底色/文字色外，额外读取**最后一列**文本，
按 `FeThemeStatusColor` 取语义色：

```
accessible/clean/running  → Accent（绿）
INACCESSIBLE/hidden/
  modified/FAILED/blocked → Danger（红）
suspicious/unknown/?      → Warn （黄）
其它                       → Text
```

选中行不覆盖前景色（保持高对比）。约定"语义状态在最后一列"与现有各页
列布局一致（Ring3 Access State / State / Note）。
