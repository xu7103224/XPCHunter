## Repair Startup

正向（有脏项）：

    reg add HKLM\...\Run /v ZQBrokenStartup /d "C:\Users\Public\nonexistent_zq.exe -test"
    --startup-op-cli repair
    Repair Startup: checked=38 repaired=1

## 期间修掉的两个真实缺陷（教训）

初版 Repair Startup 只按"Data 里的路径是否存在"判断，结果误删了 5 项正常
启动项：

    removed: SecurityHealth  %windir%\system32\SecurityHealthSystray.exe
    removed: WebCheck        {E6FB5E20-DE35-11CF-9C87-00AA005127ED}
    removed: WebCheck        （同上）
    removed: Userinit        C:\Windows\system32\userinit.exe,
    removed: Shell           explorer.exe

其中 Shell / Userinit 是 Winlogon 的关键值，被删后系统无法正常登录。
已当场恢复：

    reg add HKLM\...\Winlogon /v Shell    /t REG_SZ /d explorer.exe /f
    reg add HKLM\...\Winlogon /v Userinit /t REG_SZ /d "C:\Windows\system32\userinit.exe," /f
    reg add HKLM\...\Run /v SecurityHealth /t REG_EXPAND_SZ
            /d "%windir%\system32\SecurityHealthSystray.exe" /f

根因两条，已修：

1. **没有展开环境变量**：`%windir%\system32\...` 直接当文件名比较，
   必然"文件不存在"。现在两处调用都先 ExpandEnvironmentStringsA。
2. **没有区分值类型**：Shell/Userinit/AppInit_DLLs 的 Data 不是文件路径。
   Repair Startup 现在只处理 Location 含 "Run" 的项；
   Delete(Startup And File) 对非 Run 类位置只删注册表值、绝不删文件
   （用户点 Delete 的语义就是删这项，但不该连带伤害系统文件）。
