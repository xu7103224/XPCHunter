## 四、原版对话框 ID 布局（可推断的架构）

主窗口 `CProfessionalDialog`（511x313）只有一个 `SysTabControl32 id=1000`，
说明**主 Tab 页全部是运行时动态创建的子对话框**（每个页面对应上面列出的各类），
而不是静态资源。这也是 MENU 资源为 0 的原因——菜单和 Tab 标题都在代码里构造。

各页面容器的控件 ID 分布（从 87 个模板归纳）：

| ID 段 | 用途 |
|---|---|
| 1000~1010 | 主框架 / 进程页 |
| 1011~1030 | 进程子页（模块/线程/句柄/内存/窗口） |
| 1059~1094 | 内核/网络页列表 |
| 1104~1139 | 查找/锁定类对话框 |
| 1153~1188 | 内存/热键/其它 |
| 1218~1260 | 注册表 / 反汇编 / 隐藏项 |
| 1281~1326 | 多 Tab 复合页（网络其它、注册表监控） |
| 1250/1068/1069/1102 | About 对话框文本 |

## 五、与原版功能的定位结论

原版是 **MFC 单文档 + 动态 Tab 页 + 82 个对话框类** 的成熟商业软件（V1.6，2025 年版权）。
它的功能面覆盖：

1. **进程**：9 种子视图（模块/线程/句柄/内存/窗口/热键/定时器/反汇编/无签名）
2. **内核**：12 类（模块/驱动对象/HAL/通知/定时器/工作项/过滤/Minifilter/GDT/内存 dump）
3. **钩子**：8 类（inline/对象类型/消息/Ring3/用户/SSDT/APFN/隐蔽代码）
4. **网络**：10 类（端口/连接/SPI/防火墙/NDIS/链路/IE 插件/IFEO）
5. **注册表**：12 类（完整编辑器 + 查找 + 隐藏项 + 锁定 + 变更监控）
6. **文件**：8 类（磁盘/搜索/MD5/解锁/关联/重命名/Pending）
7. **系统**：9 类（体检/WDF/用户/输入法/火眼/反木马）
8. **启动/服务/计划任务**：4 类

其中**每个"类"在界面上就是一个可下钻的列表视图**，原版通过
右键菜单 + 双击 进入下一层，这是它功能密度的来源。
