# 第二步增量 3：Process 页导出 CSV（2026-10-28）

范围：把**当前过滤 + 排序后的可见行**导出为 CSV。不动外观骨架、驱动、协议。

## 一、实现内容

### 1.1 共享行索引（关键设计）

导出必须与屏幕所见**逐行同序**，否则"导出"就没有意义。为此把
`ProcRenderRows` 里"过滤 → 排序 → 索引"那段抽成 `ProcBuildOrder()`：

```c
static ULONG ProcBuildOrder(int **OutOrder);   /* 渲染与导出共用 */
```

- 过滤先于排序（只把命中行放进索引，qsort 规模随之缩小）；
- 返回行数，调用方负责 `free()`；
- `ProcRenderRows()` 与 `FeProcPageExportCsv()` 都调它 ⇒ 顺序天然一致，
  不存在"屏幕一个序、文件另一个序"的可能。

### 1.2 CSV 写入（`FeProcPageExportCsv`）

- **UTF-8 BOM**（`EF BB BF`）开头：Excel 双击打开时中文路径不乱码；
- 表头 `PID,Name,Path,EPROCESS,Ring3AccessState`；
- 行尾 **CRLF**（RFC 4180）；
- `CsvQuote()` 按 RFC 4180 转义：含逗号/双引号/换行的字段用双引号包裹，
  内部引号翻倍；
- 空 Name 写 `(?)`，与界面一致。

### 1.3 UI

- `IDC_PROC_EXPORT`(1034) "Export CSV" 按钮，紧贴过滤框右侧
  （过滤框 10..270，按钮 278..368，同 y 轴 8px 间隙）；
- `WM_COMMAND` → `FeProcPageExport()`：写 `%TEMP%\PCHunter_Processes.csv`，
  状态行回报 `Exported N rows (filtered) to <path>`；
- `WM_SIZE` 里与过滤框同排重排；`PageShow` 控制只在本页可见；
- 新增 `--export-procs PATH` 启动参数：走**同一个** `FeProcPageExportCsv`，
  导出后退出并返回 `rows ? 0 : 1`，供自动化验收。

## 二、验收

### 2.1 导出自检（`--selftest-export-cli`，进程内逐字节比对）

样本含 CSV 特殊字符（`has,comma` / `q"uote`），按 PID 升序输出到临时文件后
原样读回比对：

```
export selftest: CSV content matches (231 bytes)
export selftest: filter honored (only matched rows)
export selftest: PASSED
```

比对的是**完整文件字节**（含 BOM、表头、转义、CRLF），不是子串匹配。

### 2.2 真实路径三情形（`--export-procs`，连驱动取真数据）

| 情形 | 输出 | CSV 大小 | 数据行 |
|---|---|---|---|
| 无过滤 | `exported 10 rows` | 534 B | 10 |
| `--filter nomatch-abc` | `exported 0 rows` | 44 B（仅 BOM+表头） | 0 |
| `--filter INACCESSIBLE` | `exported 10 rows` | 534 B | 10 |

字节数自洽：3(BOM) + 41(表头) + 10×49 = 534；无命中时 3 + 41 = 44。

CSV 实际内容（`cat -A`，`^M$` = CRLF，`M-oM-;M-?` = BOM）：

```
M-oM-;M-?PID,Name,Path,EPROCESS,Ring3AccessState^M$
458383552,(?),(?),FFFFC90A604591A0,INACCESSIBLE^M$
458383552,(?),(?),FFFFC90A603E41A0,INACCESSIBLE^M$
```

10 条 EPROCESS 与 `--proclist-cli` 输出逐条一致。

## 三、本轮踩到的坑

1. **双 sweep 输出文件竞态**：参照版与拆分版共用 `cli_base.txt` 时，
   两份 bat 背靠背跑会互相覆盖，产出 270 个块、3MB 的污染文件
   （`--handles-cli` 重复 6 次）。修法：给参照版独立输出名
   （`cli_ref_new.txt`），并在跑前 `del`。
2. **guest 上的 `g_cli_sweep_ref.bat` 有重复 `set F=` 行**——早期手工编辑
   留下的。重新写了一份干净版（`g_sweep_ref_clean.bat`）。
3. **vmrun copyFileFromGuestToHost 抖动**：本次多次 `未找到文件`/`EOF`，
   改用 ntdrive `file_pull`（带 guest_tools 回退）稳定得多。
4. **`printf` 生成 bat 会吃掉 `\t`**：git-bash 的 `printf` 把 `\t` 解释成
   制表符，生成 bat 一律用 Write/heredoc。
