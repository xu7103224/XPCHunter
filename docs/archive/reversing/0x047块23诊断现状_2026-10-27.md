### 2. 原版 vs 复刻的槽值（跑完 0x047 后）
| 槽 | 原版 OGT | 复刻 |
|---|---|---|
| GT[0x2B8] | 0xFFFFF80144460920 | 0 |
| GT[0x2B9] | 0 | 0 |
| GT[0x2BA] | 0xFFFFF80144464E6C | 0 |

`GT[0x2BA]` 经 kd 符号解析 = `nt!CmpCallBackCount`；`GT[0x2B8]` 指向空链表头。
**块 2 = 注册表回调、块 3 = 回调链表**，与 SSDT 无关（此前假设错误）。

### 3. 原版 EnumerateProcessCallbackContext (0x14003EAA8) 的精确判据
函数入口读的槽与我方一致：
```
GT[0x61] 目标进程   GT[0x42D0] CurrentOffset   GT[0x43A8] SectionBase
GT[0x20] SectionSize  GT[0x21] 上界   GT[3] ImageBase   GT[2] （低32位）
```
初始化：
```
InitPESectionReadContext(SectionBase + CurrentOffset,
                         GT[0x21] - CurrentOffset, 2, 0, -1, 0, 0, ctx)
```
第一段（≤0xC8 轮）：
```
ReadPESectionEntry 失败 → 结束
Cumul += Entry[+0xF0]
类型(+0x118 指向结构 +6) == 0x545 → 结束
类型 == 0x512 且 +0x50==0x40 且 +0x58==2 且 +0x90==4
   → 再读一条；若类型 == 0x512 且 +0x50==0x40 且 +0x58==1 且 +0x88==0x40000
     Cand = (+0x78 - SectionSize + Cumul)
     Cand != 0 && Cand < GT[0x21]低32位 → GT[0x2B8] = Cand + ImageBase
第二段（≤0x12C 轮）：
类型 ∈ {0x4B1,0x175,0x472} 且 (+0x28 & 4) 且 +0x50==0x40000
   Cand = (+0x70 - SectionSize + Cumul) → GT[0x2BA] = Cand + ImageBase
```
**我方 Minifilter.c 的这段判据经逐条核对与原版一致**（`+0x58==2`/`+0x90==4`
在第 1 层、`+0x58==1`/`+0x88==0x40000` 在第 2 层，均正确）。
所以「字段偏移写错」这个假设**不成立**，不需要改这里。
