# 第三步-4：状态图标列（2026-10-28）

补齐第三步要求的"图标"部分。

## 一、实现

### 图标来源：运行时 GDI 生成，不依赖资源文件

`FeThemeIconList()` 在内存里用 `CreateDIBSection` + `Ellipse` 画 4 个 16×16
实心圆点，交给 `ImageList_Create`：

| 槽位 | 颜色 | 语义 |
|---|---|---|
| 0 | Accent 绿 | 正常（accessible / clean / running） |
| 1 | Danger 红 | 异常（INACCESSIBLE / hidden / modified / FAILED / blocked） |
| 2 | Warn 黄 | 可疑（suspicious / unknown / ?） |
| 3 | TextDim 灰 | 其它 |

三个好处：不需要 .ico/.bmp 文件、不需要在构建脚本里嵌资源、**颜色天然跟随
主题**（换深/浅色板时图标同步变）。

- 图标背景先刷 `Panel` 色，再叠圆点——24 位 DIB 没有 alpha 通道，
  这样与列表底色一致，不会出现白底方块；
- `FeThemeStatusIconIndex(text)` 是纯函数（语义色 → 槽位），可被自检验证。

### 挂载

`FeThemeAttachIcons(hList)`：
- `ListView_SetImageList(hList, himl, LVSIL_SMALL)`；
- 追加 `LVS_EX_SUBITEMIMAGES`（让**子项**也能显图标，不只第 0 列）。

15 个 ListView 统一调用，与 `LVS_EX_DOUBLEBUFFER` 一起挂。

### 填行

`ProcRenderRows` 的状态列（索引 4）改为：

```c
item.mask = LVIF_TEXT | LVIF_IMAGE;
item.iSubItem = 4;
item.pszText = acc ? "accessible" : "INACCESSIBLE";
item.iImage = FeThemeStatusIconIndex(item.pszText);
```

图标与状态文字同色同义，一眼可分。

## 二、验收

### 2.1 自检（`--selftest-theme-cli` 扩展）

```
  icon "accessible"   -> 0 OK
  icon "INACCESSIBLE" -> 1 OK
  icon "suspicious"   -> 2 OK
  icon "whatever"     -> 3 OK
  icon ""             -> 3 OK
  iconlist images=4 OK
  palette differs: bg dark=1E1E1E light=F0F0F0 OK
theme selftest: PASSED
```

`iconlist images=4` 是**真实调用 `FeThemeIconList()` 后数出来的**，
不是常量断言——证明 GDI 生成路径可用。

```

  doublebuffer=True                  ← 0x10000，双缓冲生效
```
