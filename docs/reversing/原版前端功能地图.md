# 原版前端功能地图（PCHunter64.exe）

来源：从 `samples/PCHunter_2024.09.02/PCHunter64.exe` 直接提取的宽字符串表
（10536 条），按功能区域归档。主 Tab 定义集中在文件偏移
`0x457030..0x4572E0`，是最可靠的结构证据。

---

## 四、结论

原版前端不是一个简单的命令转发壳，它包含：

- **14 个功能页**，其中 10 个依赖驱动；
- **7 个进程子视图**（模块/线程/句柄/窗口/内存/定时器/热键）；
- **自保护与操作拦截**（6 类 Forbid + SSDT/ShadowSSDT 自保护）；
- **Rootkit 专杀**（MBR、ZeroAccess、Safeboot、LSP）；
- **体检报告生成与导出**；
- **云查杀集成**（金山火眼，HTTP 上传 + 结果回查）；
- **内置反汇编器**。

驱动侧 283 条命令已经覆盖了这些功能所需的内核能力；
缺的是前端把这些能力串成界面的那一层。
