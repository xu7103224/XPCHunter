# frontend.c 结构拆分：第一步完成记录（2026-10-28）

目标：`frontend.c`（6,880 行）按页拆分，**不改任何外观与行为**。
验收标准：全部 CLI 输出与拆分前基线逐字节一致。

## 一、基线方法论（先于任何改动）

CLI 输出含活系统数据，"逐字节一致"必须区分实现差异与系统状态漂移：

1. 同 boot 连采两遍（T0/T1），逐条比对——**T0/T1 自身即不同的条目
   天然时变**，从严格验收集剔除（其拆分后输出只要求与 T0 或 T1 一致）；
2. T0/T1 相同的条目进入**严格集**：拆分后必须逐字节相同。

采集参数的安全化：PID 类入口固定传 4（System，跨启动稳定）；
地址类传 KUSER_SHARED_DATA 内核视图固定地址 `0xFFFFF78000000000`；
内核改动类入口一律走安全错误路径（`--kill-cli/--kill28-cli 999999`、
`--ssdt-restore-cli 999999`）。`--restorehooks-cli/--cbtable-restore`
不在 sweep 内（会改内核状态），其分发正确性由代码逐字搬移保证。

### 基线结论（45 条 sweep 条目）

| 分类 | 条数 | 明细 |
|---|---|---|
| 严格稳定 | **43** | 全部 G4 官方条目 + 增补条目 |
| 天然时变 | 3 | `--exam-cli`（内嵌时间戳+活计数）、`--fireeye-cli`（尾部未初始化缓冲，逐次必变）、`--filever-cli`（**既有 bug**：参数拷贝尾部带垃圾字节，T0 解析失败/T1 正常，非确定性） |

## 二、拆分内容

### 2.1 CliMain.c / CliMain.h（新增，1,332 行）

46 个 CLI 入口从 `WinMain` 的 if 链（原 5907–6847 行）机械搬移：

- 每个 CLI 块 → 独立处理函数 `static int Cli<名>_<序号>(const char *lpCmdLine)`，
  **函数体逐字保留**，仅在块首插入
  `if (!(<原始条件>)) return FE_CLI_NEXT;`；
- `FeCliDispatch` 按**原源码顺序**走链，首个非 `FE_CLI_NEXT` 即返回
  —— strstr 首匹配语义是承重的（`--restorehooks-cli` 先于 `--hooks-cli`，
  后者是前者的子串；`--cbtable-cli`/`--ssdt-cli` 等同理需保序）；
- 全不命中返回 `FE_CLI_NONE`，WinMain 据此落入 GUI 路径；
- `RunHeadless`（--scan-cli 的 G2 扫描器）与 `RunProcListCli` 原样搬入。

## 四、拆分过程中修掉的变换器 bug（记录供复用）

机械拆分脚本 `build/split_frontend.py` 三次迭代修掉三个解析缺陷：

1. **块闭合行未跳过**——深度归零后 `i` 仍指向 `}`，外层循环把每个 `}`
   当独立透传块（表现为 80 块里混着 47 个 "(pass) }"）；
2. **`{` 在下一行的块**——`if (...)` 与 `{` 分行时被误判为单语句块；
3. **多行注释吞并**——`/*` 后的续行（不以 `*` 开头的）需持续吞到 `*/`。

另两个非脚本坑：批处理内中文注释导致 guest cmd 返回 255（再次踩中，
g_r031.bat 首版）；build_um.bat 的路径分隔符是**双反斜杠**（`\\frontend.obj`），
单反斜杠的匹配串永远打不中。

### 5.4 本轮踩坑（记录供复用）

1. sed 对 `set F=` 行做替换时反斜杠被吞（`C:SERSPUBLIC...`）——
   改用 python 按行重写；
2. 竖排 for 循环里 `goto` 标签使 guest cmd 会话卡死——等待用
   `if exist ... (type ...) else (echo NOFLAG)` 单行式；
3. `runScriptInGuest` 引号嵌套在 git-bash 下必坏——一律走
   "写 bat 文件 → copyFileFromHostToGuest → runProgramInGuest" 三步；
4. Win32-OpenSSH 私钥属主必须是 SYSTEM（`icacls /setowner`），
   属主为普通管理员账号时 sshd 报 "UNPROTECTED PRIVATE KEY FILE" 拒载；
5. `$WINDOWS.~BT` 升级暂存里的 sshd.exe 是 delta 碎片（451KB 不可执行，
   报 216），完整二进制须从 GitHub Win32-OpenSSH release 取。
