# 第三步-1：深色主题 + 列表自绘 + 双缓冲（2026-10-28）

表现层第一步。**只改绘制，不动控件创建/布局/数据流**，因此 46 条 CLI 输出不受影响。

## 一、新增主题模块

| 文件 | 内容 |
|---|---|
| `inc/FeTheme.h` | `FE_THEME_COLORS` 调色板（12 个语义色位）+ 主题切换/状态色/custom draw 接口 |
| `src/FeTheme.c` | 深色与浅色两套配色、画刷缓存、语义色映射、ListView custom draw |

设计约束：**色值只在 FeTheme.c 出现一次**，视图代码不写字面量颜色。
这样后续换肤或做主题切换只需改一处。

### 调色板（深色）

```
Bg       #1E1E1E      Panel    #252526      Text     #D4D4D4
TextDim  #9A9A9A      Header   #2D2D30      HeaderTx #C8C8C8
Select   #094062      SelectTx #FFFFFF      Grid     #3A3A3D
Accent   #6AC87A（绿） Warn     #E0B050（黄） Danger   #E06C6C（红）
```

### 语义色映射

`FeThemeStatusColor()` 按状态文本大小写无关匹配：

- **Danger（红）**：`inaccessible` / `hidden` / `modified` / `hooked` / `failed` / `blocked`
- **Warn（黄）**：`suspicious` / `unknown` / `?`
- **Accent（绿）**：`accessible` / `clean` / `ok` / `running`

## 二、接入点（frontend.c）

| 消息/位置 | 处理 |
|---|---|
| `wc.hbrBackground` | `FeThemeBgBrush()` 替换 `COLOR_BTNFACE` |
| `WM_ERASEBKGND` | 用主题底色填整个客户区（避免拖动时白闪） |
| `WM_CTLCOLORSTATIC/BTN` | 静态文本/按钮底色 + 文字色；进程状态行额外按语义着色 |
| `WM_CTLCOLOREDIT/LISTBOX` | 编辑框（过滤框、命令框）用 Panel 底色 |
| `WM_NOTIFY` → `NM_CUSTOMDRAW` | 三阶段：PREPAINT 请求 ITEMDRAW+POSTPAINT；ITEMPREPAINT 设 `clrText/clrTextBk`；POSTPAINT 补空白区底色 |
| 15 个 ListView | 追加 `LVS_EX_DOUBLEBUFFER`（双缓冲，防闪烁） |

**POSTPAINT 补空白区是必需的**：ListView 的行下方/右侧由系统用窗口底色填充，
custom draw 覆盖不到，只设 item 颜色会留下大片白底。

## 三、验收（像素级实测）

截图后按坐标采样，确认深色确实生效：

| 采样点 | 实测 RGB | 期望 |
|---|---|---|
| 列表数据行 | `(37,37,38)` | Panel `#252526` ✓ |
| 列表右侧空白 | `(37,37,38)` | Panel ✓ |
| 列表下方空白 | `(37,37,38)` | Panel ✓ |
| 进程状态行 | `(30,30,30)` | Bg `#1E1E1E` ✓ |
| 纯白像素占比 | **1.4%** | 仅按钮/边框等系统绘制部分 |

修复前：列表右侧/下方是大片 `(255,255,255)` 纯白（custom draw 未覆盖空白区）。
修复后全部变为 Panel 底色。
