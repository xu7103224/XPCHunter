## 一、`FindKernelObjectFieldOffsetsWin10`（0x1400152D4，1908 字节）

**身份**（已定案，见命名审计 §5）：Win10 内核对象字段偏移定位器，
由 `SelectMiniFilterDirEnumCallback` 在**构建号 >= 0x2800** 时调用（无参）。

**产出（GT 写，共 6 处）**：

| 顺序 | GT 槽 | 写入值 | 消费者 |
|---|---|---|---|
| 第 1 块 | `0x332` | 字段偏移 RVA | `CmdWriteKernelObjectField` 等 |
| 第 1 块 | `0x333` | 字段偏移 + 镜像基址 | `CmdWriteKernelObjectField` |
| 第 1 块 | `0x8EE` | 另一字段偏移 RVA | —— |
| 第 1 块 | `0x8EF` | 另一字段偏移 + 镜像基址 | `CmdWriteKernelObjectField`、`SwapKernelObjectPointerWin10` |
| 第 2 块 | `0x337` | 偏移 + 镜像基址 | `CmdEnumKernelObjectTable` |
| 第 2 块 | `0x334` / `0x335` | 偏移 / 偏移+基址 | `CmdWriteKernelObjectField` |

**输入**（GT 读）：`0x8CC`、`0x8CD`、`0x900`（由 `InitEprocessOffsetsWin10_*` 写入）、
`0x8CD`、`0x4459`，以及 `0x20`(ntoskrnl PE 大小) / `0x3`(镜像基址)。

**结构（三层嵌套）**：

```
1) 取节名 ".PAGE"（字符串常量 0x4741502E = ".PAG" + 'E'）：
     FindPESectionByName(...)      → 得文件内偏移（用于算扫描范围）
     FindPESectionByNameReturnVa() → 得节 VA
   扫描范围 = [VA, VA + 节大小)，结束边界另有 r13+0x30 的前置检查
2) 外层：逐字节扫描（每次 +1），找 x64 指令模式
     要求 [p]==0x48 && [p+1]==0x8D          ; LEA（关键指令）
     r14d = *(int*)(p+3) - 镜像大小 + (p+7) ; RIP 相对位移算出的目标 RVA
     若 r14d 无效(0 或 >= r12d) → 前进一字节
3) 按紧随的指令模式分两类别：
     A 类：[p+7]==0x48 && [p+8]==0x89 && [p+0xA]==8   ; 48 89 xx 08（MOV [reg+8], reg）
          → 进入内层节区扫描（次数上限 0xA = 10）
            内层：InitPESectionReadContext + ReadPESectionEntry，
                  匹配 0x512 型 && +0x88==0x40000 && +0x70!=0 && +0x50==0x40
                  → 执行第 1 块 4 个 GtWrite（0x332/0x333/0x8EE/0x8EF）
     B 类：其它 → 跳到 loc_140015856，走第 2 块判定
4) 第 2 段（loc_140015893）以"状态标志"驱动，依次匹配：
     0x547 型 && (标志 & 0x800000) && +0x70==0x1000 && 某字段等于镜像大小
       → 写 GT 0x337（偏移 + 镜像基址）
     0x53C..0x543 型 && (标志 & 0x2000000) && +0x70 == 0xFFFFF78000000014
       → 该立即数是 **KUSER_SHARED_DATA + 0x14**（基址 0xFFFFF78000000000）
     0x558 型 && 位26 置位 && 某字段非 0
     0x50E 型 && +0x88==0x40000 && +0x50==0x40
     计数上限：第二层 0x14(20)、第三层 0xF(15)
5) 三个**并行状态标志**贯穿全程：`r8b`（A 类已命中）、`r14b`、`dl`（B 类已命中）、
   另有 `bl`、`dil` 作为"已置候选"标记。退出条件为三者（r8b/r14b/dl）同时为 1。
```

**实现难点（如实记录）**：
- **5 个并行状态标志的转移**必须在每条分支上逐一跟踪，是最易出错处；
- 三层循环的**边界与提前退出**共 4 处（`0xA`/`0x14`/`0xF` 计数上限 + 标志组合退出）；
- 第 2 段的进入条件依赖第 1 段的产物（`Value[]` 字节数组），
  故**不能把两段当作独立代码实现**。
- **建议做法**：先按上面表格搭出三层循环与状态标志，再逐分支对照反汇编补齐；
  每补一个分支即编译（本文件已被枢纽调用，签名已修正为无参）。

**同族说明**：`FindKernelObjectFieldOffsetsWin8`(0x140015A48, 1257B) 与
`FindKernelObjectFieldOffsetsWin10Early`(0x140015F34, 1231B) 结构同源
（同一函数的构建号变体），实现第一个后可逐指令差分复用到另两个。
